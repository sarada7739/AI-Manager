# ADR-0008 配色をインディゴ基調に変更し、稼働中の表示に光彩（グロー）と背景グラデーションを許可する

- 日付: 2026-09-03
- 状態: 採用
- 関連: harness.md §6 / DESIGN.md §1, §2, §3, §4.3, §9 / ADR-0006

## 文脈

第 1 段階（read-only）完了後、利用者から「添付画像のような色合いに変更してほしい。パネルの位置やレイアウトは変えなくてよく、フォント・色の光り方・グラデーションに着目してほしい」との指示があった。
参考画像は深い紺〜藍のキャンバスに紫〜青のアクセント、稼働中要素の柔らかい光彩、ページ全体の緩やかなグラデーション、ページタイトルのセリフ体という構成。
ADR-0006 で採用した「近黒 + ミント 1 色、影なし」は、この指示と両立しない。

harness.md §6.1 の「添付スクリーンショットの配色を流用しない」は、Phase 0 で渡されたクリーム地 + テラコッタの画像を指す。今回の画像は利用者が配色変更のために新たに提示したものであり、その禁止の対象ではない。

## 決定

- **配色**: 無彩色 6 段を藍寄りの 6 段に置き換える（`#06060f` → `#0b0b1c` → `#12122b` → `#1a1a3c`、境界 `#2a2a60` / `#3b3b78`）。テキスト 4 段は薄い藤色寄りにする。すべて対 surface-2 で従来と同等以上のコントラスト比を保つ（§2.2 の表）。
- **シグナル**: 「画面で唯一光る色」をミント `#70dcd3` からバイオレット `#9d8cff` に変える。役割（稼働中のみ）は変えない。フォーカスは青 `#6ea8ff`。作業中・エラーは据え置く。
- **光彩とグラデーション**: §4.3 の「影は使わない」を「**装飾の影は使わないが、稼働中の要素とページタイトルにだけ光彩を使う**」に改める。光彩・グラデーションはトークン（`--glow-*`, `--gradient-*`）として定義し、CSS Modules には生の `rgba()` / hex を書かない（design-tokens テストがこれまで通り検出する）。ページ背景は `--gradient-page`、カードは `--gradient-surface` を重ねる。塗りつぶしボタンは `--gradient-primary`。
- **書体**: ページタイトルだけ `--font-display`（Georgia / Cambria / 游明朝。外部フォントは読まない）と `--text-2xl` を使う。本文・UI は `--font-ui` のまま。harness.md §6.2 (3) の「書体は 1〜2 種」は、表示用セリフ 1 種を加えた 3 種（ui / mono / display）に緩和する。
- **変えないもの**: レイアウト、余白、角丸、状態の形とラベル、点滅なし、ライトテーマなし、外部フォントなし、`prefers-reduced-motion` の扱い。

## 結果

- 利用者の意図（紫〜青の光る管制画面）を反映しつつ、「大胆さは 1 か所（稼働中）に集中」「色 + 形 + ラベル」「トークン以外の値を書かない」という harness §6 の原則は維持する。
- DESIGN.md §9 と `tokens.css` を同時に更新する。トークンの追加は `--gradient-page` / `--gradient-surface` / `--gradient-primary` / `--glow-signal` / `--glow-signal-dot` / `--glow-title` / `--font-display` / `--text-2xl` / `--leading-2xl`。
- ADR-0006 の「ミント 1 色」「影なし」の 2 点は本 ADR で上書きする。
