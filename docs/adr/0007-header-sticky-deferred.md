# ADR-0007 ヘッダ帯の固定表示（sticky）は第 1 段階では行わず、フィルタバーの固定を優先する

- 日付: 2026-09-03
- 状態: 採用
- 関連: DESIGN.md §5.1 / T-020, T-021, T-025

## 文脈

DESIGN.md §5.1 は「ヘッダ帯とフィルタバーは `position: sticky`」と定めている。
T-020 でヘッダ帯を、T-021 でフィルタバーをそれぞれ `top: 0` の sticky にしたところ、両者が同じ位置に吸着して
後勝ちのフィルタバーがヘッダ帯を覆い隠した。両立にはフィルタバーの `top` にヘッダ帯の高さを与える必要があるが、
DESIGN.md §9 にヘッダ帯の高さを表すトークンが無く、CLAUDE.md §5「DESIGN.md に無い値を使わない」により
生の px も書けない。

## 決定

- 第 1 段階ではヘッダ帯を sticky にしない。絞り込み操作の起点であるフィルタバーの固定を優先する（T-025）。
- DESIGN.md §9 / `tokens.css` に `--header-height` を追加した時点で、ヘッダ帯を `top: 0`、フィルタバーを
  `top: var(--header-height)` の sticky にして両立させる。合わせて `z-index` も `--z-*` トークンに寄せる。

## 結果

- ヘッダ帯（タイトル・時計・件数・表示切替・更新）はスクロールすると画面外に出る。件数と自動更新の状態は
  フィルタバーの「表示 N 件」と `LiveStatus` で代替できる。
- DESIGN.md §5.1 に本 ADR への参照を残し、実装との差異が意図的なものであることを明示した。
