# ADR-0002 データソースは Windows ネイティブのホームディレクトリのみを対象とする

- 日付: 2026-09-02
- 状態: 採用
- 関連: harness.md §1.3, §2.3 / docs/RESEARCH.md §1

## 文脈

harness.md §1.3 は「Windows ネイティブか WSL か、混在か」を最初に確定させるよう求めている。
実機調査で WSL は未インストールであり、`\\wsl$` / `\\wsl.localhost` は到達不能だった。

## 決定

- 読み取り対象は `os.homedir()` 配下の `.claude/` と `.codex/` のみとする。
- WSL 側パス（`\\wsl$\...`）の探索コードは書かない。設定でルートを追加できる余地（`local-data/config.json` の `roots[]`）だけ残す。
- パスの一意性判定は大文字小文字を無視して比較する（NTFS 前提）。

## 結果

- 実装とテストから WSL 分岐が消え、Phase 3 のタスク数が減る。
- 将来 WSL を併用する場合は `roots[]` にパスを追加する ADR を起票する。
